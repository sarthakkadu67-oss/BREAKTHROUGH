
# BREAKTHROUGH - Premium Food Delivery Platform

Breakthrough is a modern, high-performance food discovery and delivery application designed to redefine the user experience. Built with a focus on speed, aesthetics, and intelligent discovery.

## 🚀 Features

- **Semantic AI Search**: Ask naturally (e.g., "Spicy food for a rainy day") and get curated results.
- **Live Order Tracking**: Real-time simulated order status widget.
- **Premium UI/UX**: Dark mode aesthetic, smooth framer-motion-like animations, and glassmorphism effects.
- **Smart Filtering**: Filter by dietary preference (Veg/Non-Veg), delivery time, and health scores.
- **User Profile & Checkout**: Complete flow from adding items to cart, managing addresses, and placing orders.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, Custom CSS Animations
- **Icons**: Lucide React
- **Build Tool**: Vite
- **AI Integration**: Google GenAI SDK

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sarthakkadu18/breakthrough.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file and add your API key (optional for UI, required for AI search):
   ```env
   VITE_API_KEY=your_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```
